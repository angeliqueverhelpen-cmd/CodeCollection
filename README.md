## Projects

### 📊 Content Analytics Dashboard

A dashboard concept for comparing social media performance across different platforms.

#### Features

* Overview of TikTok, Instagram, and YouTube statistics
* Post performance across the latest seven posts
* Total views per platform
* Visual comparison using charts
* Dashboard-style layout and data presentation

### Technologies
HTML5, CSS, JavaScript

**Built as a learning exercise. Data is illustrative.**

### What I'm Practising

* Working with arrays and objects
* Displaying and organising data
* Building interactive interfaces
* CSS layouts and responsive design
* Turning Ideas into practical applications
